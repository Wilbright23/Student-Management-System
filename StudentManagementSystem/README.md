# Student Management System (CLI-Based)

## Tags
- Java
- OOPs
- Collection Framework
- File Handling
- Exception Handling
- Java 8+ Features

## Features
1. Add student
2. View all students
3. Update student
4. Delete student
5. Search student by name
6. Sort by CGPA
7. Sort by name
8. Display statistics
9. Persistent storage using a text file

## OOP Concepts Used
- Encapsulation: private fields with getters and setters
- Classes and objects
- Constructors
- Abstraction through manager methods
- Method organization

## Collection Framework
- ArrayList
- Comparator
- Collections sorting through List.sort()

## How to Run

1. Save the Java file as `Main.java`.
2. Open the terminal in the same folder.
3. Compile:

```bash
javac Main.java
```

4. Run:

```bash
java Main
```

The application automatically creates and updates `students.txt` in the same folder.
